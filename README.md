## 📂 Proyectos destacados

### 🔹 ControlHUB - Sistema de Gestión Centralizada

Aplicación de escritorio desarrollada en **Python** con interfaz gráfica (**CustomTkinter**), diseñada para el monitoreo y gestión remota de equipos en red. Permite la ejecución de comandos CMD, reinicios, visualización de logs, control de versiones, gestión MySQL y transferencia de archivos.

**Tecnologías:** Python · CustomTkinter · WMI · MySQL · ThreadPoolExecutor · PsExec · VNC

🔗 [Repositorio demo](https://github.com/rondoncamacho/controlhub-desktop_demo)

---

### 🔹 Proyecto de Infraestructura Virtualizada (Sysadmin Lab)

Laboratorio de ingeniería diseñado para simular una red corporativa real utilizando **KVM** como hipervisor. Incluye enrutamiento avanzado con iptables, túneles seguros WireGuard, balanceo de carga con HAProxy, automatización con Bash y políticas de seguridad (Zero Trust, hardening de SSH, Vault, Fail2ban).

🔗 [Ver repositorio](https://github.com/rondoncamacho/sysadmin-devops-roadmap)
